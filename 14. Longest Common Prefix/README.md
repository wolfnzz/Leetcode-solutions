14. Longest Common Prefix (легкая)

Напишите функцию для поиска самой длинной строки общего префикса среди массива строк. Если общего префикса нет, верните пустую строку "".

Алгоритм решения:  

По условию искомый префикс должен присутствовать во всех строках, т.е. он гарантированно является подстрокой (или полной копией) первой строки в массиве. Можно использовать первую строку как шаблон.
Во внешнем цикле пройдем посимвольно по строке-шаблону. Во внутреннем цикле проверим есть ли символ с таким же индексом во всех остальных строках массива. Проверка прерывается в двух случаях: 1) если символ в одной из строк не совпадает с символом шаблона; 2) если индекс проверки превысил длину текущей проверяемой строки (т.е. более короткое слово полностью совпало, и префикс не может быть длиннее него). При прерывании возвращается подстрока шаблона от начала до текущего индекса. Если все проверки пройдены успешно, возвращается сам шаблон целиком.

Оценка сложности:

Временная сложность: O(S), где S - суммарное количество всех символов во всех строках массива. В худшем случае, когда все строки идентичны, алгоритму придется проверить каждый символ каждой строки. 

Пространственная сложность: O(1). Используется константное количество дополнительной памяти для хранения указателей и переменных циклов.
