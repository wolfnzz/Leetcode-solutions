287. Find the Duplicate Number (Средняя)
Дан массив целых чисел nums, содержащий n + 1 элементов, где каждое число находится в диапазоне [1, n] включительно. В массиве присутствует ровно одно повторяющееся число. Необходимо вернуть это повторяющееся число без изменения исходного массива и используя константную дополнительную память.

Алгоритм решения:

Массив содержит n + 1 элементов в диапазоне от 1 до n, поэтому любое значение элемента массива может интерпретироваться как валидный индекс следующего элемента. Это позволяет представить массив как связный список, где каждый переход задается как next = nums[current]. Наличие дубликата означает, что несколько индексов ведут в одну ячейку, образуя замкнутый цикл. Задача сводится к нахождению точки входа в этот цикл.
Для решения используется алгоритм Флойда ( метод черепахи и зайца) с двумя указателями, движущимися с разной скоростью.
Сначала идет обнаружение цикла: инициализируем «Черепаху» (медленный указатель) и «Зайца» (быстрый указатель) в начале массива. Медленный указатель перемещается на один шаг (slow = nums[slow]), а быстрый - на два шага за раз (fast = nums[nums[fast]]). В списке есть цикл, поэтому быстрый указатель неизбежно догонит медленного внутри этого цикла, что подтверждает его наличие.
Затем выполняем поиск начала цикла: после встречи перемещаем медленный указатель обратно в начало списка (индекс 0), а быстрый оставляем в точке встречи. После этого двигаем оба указателя с одинаковой скоростью, т.е. по 1-ому шагу (slow = nums[slow], fast = nums[fast]). Точка, в которой они снова встретятся, является началом цикла, то есть искомым повторяющимся числом.

Оценка сложности:

Временная сложность: O(n). На первом этапе быстрый указатель встречает медленный внутри цикла менее чем за 2n переходов. На втором этапе указатели проходят путь до входа в цикл менее чем за n переходов. В худшем случае указатели проходят по массиву максимум дважды, что гарантирует строго линейное время работы.

Пространственная сложность: O(1). Алгоритм использует только две переменные типа int для хранения индексов медленного и быстрого указателей. Дополнительные структуры данных не создаются, а исходный массив не изменяется, что полностью удовлетворяет ограничениям задачи.
Замечание: можно было бы решить задачу с помощью хэш-таблицы за O(n) по времени и O(n) по памяти, но для удовлетворения строгого ограничения по памяти O(1) оптимальным выбором является все же алгоритм Флойда.
