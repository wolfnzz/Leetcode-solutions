57. Insert Interval (средняя)
Дан массив непересекающихся интервалов intervals, отсортированных по возрастанию начальной координаты. Также дан новый интервал newInterval. Необходимо вставить новый интервал в массив так, чтобы он оставался отсортированным, и объединить любые перекрывающиеся интервалы. Разрешается вернуть новый массив.

Алгоритм решения:

Раз исходный массив уже отсортирован, то нет необходимости применять ресурсоемкую сортировку. Для решения задачи создаем результирующий массив и проходим по исходному списку с помощью одного указателя i, разделяя процесс на три этапа:
1. Пока конец текущего интервала строго меньше начала нового интервала, пересечения нет. Просто добавляем текущие интервалы в результат.
2. Когда начинаются пересечения (т.е. когда начало текущего интервала меньше или равно концу нашего нового интервала), объединяем интервалы, расширяя левую и правую границы newInterval: его началом становится минимальное из двух начал, а концом - максимальное из двух концов. По завершении слияния добавляем обновленный newInterval в результат.
3. Все оставшиеся интервалы находятся строго правее объединенного отрезка. Просто добавляем их в результирующий массив до конца списка.


Оценка сложности:

Временная сложность: O(n) ( n - количество интервалов). Хотя в коде присутствует три цикла while, указатель i только инкрементируется. Таким образом, каждый элемент массива обрабатывается ровно один раз.

Пространственная сложность: O(n). Используем дополнительную память для создания нового результирующего массива result, в который в худшем случае (при отсутствии слияний) будут помещены все n элементов плюс один новый.
