268. Missing Number (легкая)
Дан массив nums, содержащий n уникальных чисел в диапазоне [0, n]. Необходимо вернуть единственное число из этого диапазона, которое отсутствует в массиве.

Алгоритм решения:
По условию массив содержит числа от 0 до n. Можем узнать сумму всех чисел при помощи формулы S=n*(n+1)/2. Переполнения здесь не случится, т.к. по условию задачи n 
ограничено (1 <= n <= 10^4): максимальная сумма составит около 5 * 10^7, что помещается в 32-битный тип int без риска переполнения. Далее в цикле проходим по данному 
массиву и вычитаем из полученной ранее суммы каждое число, которое считали. Значение, которое останется в переменной суммы после завершения цикла, и будет являться 
недостающим числом (так как оно единственное не было вычтено).

Оценка сложности:
Временная сложность: O(n). Требуется один раз пройти по всем элементам массива (цикл for), что занимает линейное время. Вычисление суммы по формуле происходит за время O(1).
Пространственная сложность: O(1). Не используем дополнительные структуры данных, размер которых зависит от n. Для хранения размера массива и промежуточной суммы 
требуются только две переменные типа int, что занимает константное количество памяти.
