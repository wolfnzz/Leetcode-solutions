23. Merge k Sorted Lists (сложная)

Дан массив из k связных списков, где каждый список уже отсортирован по возрастанию. Необходимо объединить все эти списки в один отсортированный связный список и вернуть его.


Алгоритм решения:

Для слияния нескольких списков используется структура данных очередь с приоритетом (priority queue. Идея заключается в том, что минимальный элемент среди всех списков в любой момент времени обязательно находится на вершине одного из этих списков. Также для использования priority queue с указателями на объекты ListNode реализована структура Compare и перегружен оператор () для сортировки по возрастанию значений в списках.
Сначала инициализируем очередь и помещаем в нее первые узлы всех непустых списков. Создаем фиктивный узел temp для удобного формирования итогового списка. В цикле извлекаем из кучи узел с минимальным значением и присоединяем его к концу формируемого ответа. Сразу после извлечения минимального узла, проверяем, есть ли за ним следующий узел в его исходном списке: если есть, то помещаем его в кучу. Повторяем процесс, пока куча не станет пустой. В конце переносим начало отсортированного списка и удаляем фиктивный узел.

Оценка сложности:

Временная сложность: O(N log k), где N - количество узлов во всех списках, k - количество списков. В куче одновременно хранится не более k элементов. Вставка и извлечение из кучи размера k занимает O(log k) времени. Т.к. через кучу проходит каждый из N узлов, то итоговое время составит O(N log k). 

Пространственная сложность: O(k). В доп.памяти хранится только очередь с приоритетом, размер которой никогда не превышает количество списков k. Сам итоговый список формируется путем перестраивания существующих указателей без выделения памяти под новые узлы (за исключением одного вспомогательного узла).
